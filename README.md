# DSA Practice

Collection of DSA and LeetCode solutions, plus low-level design practice.

## Structure

```text
leetcode/                       # Auto-synced solutions, one folder per LeetCode problem
Data Structures & Algorithms/   # Manually organized solutions by problem name
LLD/                            # Low-level design implementations
Personal/                       # Personal practice solutions
```

## Languages

Python, C++, Java

## Sync Automation

`leetcode/` is kept up to date automatically via GitHub Actions on new LeetCode submissions.
